I file nelle cartelle originali del repo non sono stati modificati.

- `kafka-snippets-v9.txt`: copia della v8 + appendice Kafka 4 in fondo
- `docker-compose-kraft-single.yml`, `docker-compose-kraft-3nodes.yml`: broker
- `kafka-basics/`: ProducerDemo/ConsumerDemo... con `kafka-clients` 4.1.0 (`-Dkafka.version=2.4.1` per il client originale)
- `kafka-streams-filter-tweets/`: Streams 4.1.0
